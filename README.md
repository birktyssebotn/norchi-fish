# Norway and Chile in the Global Salmon Trade

Data wrangling and analysis case study: has Chile caught up to Norway
in the global salmon export market, or does it remain a smaller,
cheaper alternative?

**[Read the full analysis &rarr;](https://birktyssebotn.github.io/norchi-fish/)**

## What this project does

Reconciles FAO trade export data and World Bank exchange-rate data for
Norway and Chile (1976-2024) to compare export volume, market share,
and average export unit value between the two countries. The source
FishStatJ exports are wide-format, Windows-1252 encoded, and split
across separate quantity and value files -- the wrangling step fixes
the encoding, reshapes to tidy format, and merges them before any
analysis happens.

## Key finding

Chile closed most of the competitive gap with Norway by 2000 but never
closed the remaining volume gap -- Norway's absolute lead has kept
growing. Since recovering from a 2007-09 disease crisis, Chile has held
a broadly stable share of roughly one-third of combined Norway-Chile
export volume, and the historical gap in average export unit value has
largely disappeared. An initial explanation for that gap closing
(post-crisis certification catching up) did not survive a timing check
against the data, and the write-up states that directly rather than
keeping the original story.

## Reproducing this analysis

Requires R (base R only for wrangling/FX -- no tidyverse dependency)
plus `ggplot2`, `scales`, and `jsonlite` for the plotting/FX scripts,
and [Quarto](https://quarto.org) to render the write-up.

1. Download the two FAO FishStatJ exports (quantity and value, Norway
   and Chile, salmon/salmonid commodities, exports, 1976-2024) into
   `data/raw/`. See `salmon_case_study.qmd`'s Data sources section for
   the exact filter settings used.
2. Run the scripts in order from the project root:
   ```r
   source("scripts/01_wrangle_fishstat.R")
   source("scripts/02_plot_salmon.R")
   source("scripts/03_fetch_fx.R")
   source("scripts/04_plot_fx.R")
   ```
3. Render the write-up:
   ```
   quarto render salmon_case_study.qmd
   ```

## Limitations

This analysis measures reported export volume and export unit value --
not production, profitability, or global market share, and the two
countries' salmon export categories may differ in product mix in ways
the data can't separate out. Full detail is in the "What this analysis
measures" and "Limitations" sections of the write-up.
